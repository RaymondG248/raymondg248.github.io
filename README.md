# Raymond Gao Portfolio

A polished, responsive static portfolio designed for research, machine learning, computational biology, and scientific software applications.

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to Vercel

1. Create a new GitHub repository and upload all files in this folder.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Vercel will detect it as a static site. No build command is required.
4. Deploy.
